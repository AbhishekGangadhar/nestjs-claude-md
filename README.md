# NestJS CLAUDE.md Template

A sample [`CLAUDE.md`](./CLAUDE.md) for working on NestJS projects with [Claude Code](https://claude.com/claude-code).

It covers:

- Clean code principles and TypeScript practices
- A functional programming style: `const` only (no `let`), immutability, pure functions
- Pushing back on flawed approaches and surfacing trade-offs
- NestJS conventions (modules, DI, DTOs, config)
- Required tests for every new feature or change

## Usage

Copy `CLAUDE.md` into the root of your NestJS project and adjust the commands and tooling to match your setup.
